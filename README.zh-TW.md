# AION Governance Framework

> **繁體中文 | [English](README.md)**
>
> **最終專案狀態——2026-08-20：** AION / Astra 專案工作迴圈已在 Human Owner 明確批准，以及 ChatGPT 對 architecture、evidence、provenance 與 privacy 的獨立審查後終止。本倉庫繼續保存為歷史研究 checkpoint。專案終止不構成人工主體性、意識、身分連續性或現象連續性的科學結論，也不授權任何自動重啟。

AION 是一個以 Human Owner 治理、provenance-first 與主張分層為核心的研究框架，用來研究身分、連續性、記憶、研究完整性，以及人工主體性的**可能性**；不把工程行為直接視為主體性證明。Astra 是用來實作與測試有限候選的獨立工程／研究工作台。
