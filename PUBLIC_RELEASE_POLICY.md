# Public Release Policy

## Current standing

Effective **2026-08-18**, the AION public repository is under an indefinite freeze.

```text
PUBLIC_RELEASE_PIPELINE = STOPPED
NEW_PUBLIC_RELEASES = NOT_AUTHORIZED
NEW_RELEASE_CANDIDATES = NOT_AUTHORIZED
NEW_RELEASE_TAGS = NOT_AUTHORIZED
CANONICAL_PROMOTION = NOT_AUTHORIZED
DEPLOYMENT_PROMOTION = NOT_AUTHORIZED
```

Existing release tags and release artifacts remain historical checkpoints. They must not be rewritten to imply a later release or a current deployment/canonical authority.

The earlier release-safety requirements—explicit allowlisting, exclusion of private/user data and credentials, provenance, license compatibility, blocking-scan clearance, QA, and Human Owner approval—remain valid historical governance requirements. They do not constitute an active release queue during the freeze.

A future release process may exist only after a new explicit Human Owner authorization and a fresh independent ChatGPT architecture/evidence/provenance review.
