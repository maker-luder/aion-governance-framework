# Classical Rule Profile v0.1.0

`CLASSICAL_HELLENISTIC_MEDIEVAL_COMMON_V1` is a bounded engineering profile, not a claim that all classical authors or historical schools used identical rules.

| Surface | v0.1.0 rule |
|---|---|
| Planets | Traditional seven only |
| Zodiac | Tropical |
| Houses | Whole sign |
| Aspects | Conjunction, sextile, square, trine, opposition |
| Aspect orbs | Explicit engineering test profile; not asserted as a cross-author historical consensus |
| Sect | Source declares day/night from an upstream horizon calculation |
| Mercury sect | Unresolved without solar phase |
| Essential dignity | Sign-based domicile, exaltation, detriment, fall |
| Terms/bounds | Deferred; historical tables differ |
| Triplicity rulers | Deferred; historical tables and participating-ruler conventions differ |
| Decans/faces | Deferred |
| Lots | Deferred |
| Primary directions/profections/time lords | Deferred |
| Outer planets | Excluded from the classical-primary profile |

This original profile remains executable and unchanged in semantic scope in
v0.2.0. The additive profile is documented separately in
[`WESTERN_ASTROLOGY_FUSION_PROFILE.md`](WESTERN_ASTROLOGY_FUSION_PROFILE.md).

The profile names Ptolemy, Dorotheus, and Valens as source families. The accompanying source register identifies the consulted digital witnesses. These references do not establish one universal historical school, and the identifiers are not substitutes for critical editions.

See [`SOURCE_REGISTER.json`](SOURCE_REGISTER.json).
