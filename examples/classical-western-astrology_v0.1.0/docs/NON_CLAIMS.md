# Non-claims and Use Boundary

The example does not establish:

- empirical or predictive validity of astrology;
- personality, destiny, relationship, health, legal, employment, or financial conclusions;
- consciousness, subjectivity, identity, memory, or agent continuity;
- automatic AION/Astra binding;
- permission, privilege, governance authority, canonical status, or deployment approval;
- completeness across Hellenistic, Persian, Arabic, medieval Latin, Renaissance, or modern traditional schools.

Only synthetic inputs are accepted by the v0.1.0 validation contract. Output is an inspectable historical-rule computation artifact, not a decision recommendation.
