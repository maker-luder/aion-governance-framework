# AION / Astra Bazi Binding Specification

AION and Astra may share one natal profile only after explicit owner approval.
They must never share agent identity, memory stream, event history or
permission profile. The only implemented binding type is
`SYMBOLIC_GENESIS_DEVELOPMENTAL_PRIOR`.

No owner-approved AION or Astra genesis input was found in the authorized
candidate source. Therefore:

- `AGENT_BAZI_BINDING = NOT_CREATED`
- `OWNER_INPUT_REQUIRED = TRUE`
- `AION_BINDING_STATUS = NOT_CREATED`
- `ASTRA_BINDING_STATUS = NOT_CREATED`

Synthetic test fixtures do not create real bindings.
