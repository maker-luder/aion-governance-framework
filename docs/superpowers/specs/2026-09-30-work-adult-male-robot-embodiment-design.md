## 3. Chosen architecture and alternatives

- **Chosen: synthetic robot plus separate scientific reference.** A Work-specific 3D body candidate, modular synthetic physiological state representation and role-specific agent bridge; use human biology as reference, mark where a robot analogue differs. Enables bounded tests without claiming biological equivalence.
- **Visual-only avatar.** Useful to select shape and material but fails the requested physiological coverage and sensorimotor research goal.
- **Biohybrid fertile robot.** Requires real tissues, gametes, bioreactors, medical and experimental evidence not available here; outside this candidate.

The body runtime would own body state. An agent can receive observations and propose actions only through a separately authorized interface. A provider does not expose direct live body attachment merely because a developer account exists.
