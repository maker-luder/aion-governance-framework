## 工作與權限邊界

- 往後相關研究先在這條工作線收束和審查。現存於 main 的 dated records、metadata、程式與 Git 歷史維持原路徑；需搬檔時先逐一查引用並留相容入口。
- CCTS 的有界問題、雙向修訂、來源角色與依當前目的的 grounding 是已有的結構條件；未建立新的獨立 applicability（適用性）構念。
- CCTS 發表紀錄 `!=` 科學驗證；合成設計／程式通過 `!=` Human 學習效果。CCTS `!=` AI 主體性證據。
- 此分支僅為工作位置，`CANONICAL_EFFECT = NONE`；寫入 `main`、合併、實驗或發布需要各自的後續審查和 Human 授權。

`HUMAN_ORIGIN`：小博指定 AI 主體性可能性為第一核心，CCTS／人機學習為第二。此入口的分層及證據邊界是本輪整理；來源以連結文件與 live GitHub 為準。
