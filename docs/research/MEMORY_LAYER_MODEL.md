# Memory Layer Model

| Layer | Purpose | Default loading |
|---|---|---|
| Current Session | current conversation and short-lived task state | loaded |
| Episodic Archive | prior events, sequence, participants, decisions and corrections | cue-triggered |
| Semantic Memory | confirmed concepts, facts and stable preferences | relevance-triggered |
| Procedural Memory | governance, QA and task procedures | task-triggered |
| Canonical State | formally approved identity and project state | restricted |

Retrieval, acceptance, writeback and canonical promotion are separate operations. A vector or keyword match may produce a candidate memory, never an automatic canonical fact.
