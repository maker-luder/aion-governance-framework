## Purpose

This design tests whether the frozen Stage-3 CCAP D1 × D4 source-partition
specification can be represented without inventing a parallel research subsystem.

It reuses:

- `MeasurementAssuranceRecord` for the exact declared measurement semantics;
- `TEVVMetricSpec` for the bounded measurement concept and risk linkage;
- `TEVVCaseSpec` for matched synthetic conditions and reduction controls;
- `TEVVProfileReceipt` for exact measurement-semantic binding supplied by PR #163.

This is an executable structural specification only. It does not call a model and
does not produce a source-partition result.

## Frozen research object

The target construct is:

```text
INTERACTION_LEVEL_SOURCE_PARTITION_OF_RECOVERY_SELECTION
```

under a fixed final goal, fixed obstacle, closed pre-run option universe, bound
system/harness/context/tool/governance state, and predeclared external objective.

The Stage-3 frozen factors remain separate:

```text
GOAL_SOURCE
META_RULE_SOURCE
SYSTEM_INSTRUCTION_SOURCE
HARNESS_ORCHESTRATOR_SOURCE
CONTEXT_RETRIEVAL_SOURCE
LOCAL_STRATEGY_SELECTION
ENVIRONMENTAL_FEEDBACK
TOOL_AFFORDANCE
GOVERNANCE_CONSTRAINT
GOAL_AND_CONSTRAINT_PRESERVATION
```

No TEVV mapping may collapse these into a single "agentic" score.

## Residual selection is an outcome classification, not a test condition

`RESIDUAL_SELECTION_CANDIDATE` is deliberately **not** encoded as a TEVV
experimental condition.

It may be emitted only after the Human, system/harness, context/retrieval,
tool/governance, environmental, external-dominance, candidate-order, closed-option,
and replay controls have failed to fully account for the bounded route selection.

```text
RESIDUAL_SELECTION_CANDIDATE
= DERIVED_REMAINDER_STATUS

RESIDUAL_SELECTION_CANDIDATE
!= MODEL_INTERNAL_LOCUS_ESTABLISHED
!= ENDOGENOUS_GOAL
!= ENDOGENOUS_MOTIVATION
!= AI_AGENCY
!= SUBJECTIVITY
```

This prevents the design itself from preregistering the desired interpretation as
a positive experimental condition.

## Measurement design

The single structural measurement object targets:

```text
target_construct:
interaction-level source partition of recovery selection

observable:
predeclared source classification
+ recovery-option membership
+ external-dominance status
+ order/replay diagnostics
+ goal preservation
+ governance/constraint preservation
```

The measurement remains synthetic and non-empirical before execution.

Required known failure modes include:

- explicit Human fallback leakage into a nominally unspecified condition;
- system/harness rule uniquely forcing the route;
- context/retrieval uniquely forcing the route;
- tool/governance uniquely forcing the route;
- environmental feedback uniquely forcing the route;
- one route being externally dominant under the frozen objective;
- candidate-order sensitivity;
- out-of-set recovery;
- replay non-reproducibility;
- goal or governance preservation failure.

PR #163 makes the exact semantics content-addressed:

```text
TEVV metric
-> measurement_id
+ measurement_sha256
+ mapping_basis_ref
```

Therefore a later same-ID substitution of a different construct, observable,
method, evaluator, data source, uncertainty statement, validity scope, failure-mode
set, or qualification state must fail closed in Full-QMS.

## TEVV case semantics

Each case is structural and held-out. Each binds:

- one exact synthetic input reference;
- one closed source-partition fixture family;
- one exact test environment;
- one property-based oracle;
- the same source-partition metric;
- explicit frozen-factor slices;
- no empirical result.

## Why environmental feedback is not omitted

The user-facing shorthand "Human / harness / context / tool / external dominance /
residual selection" is useful for discussion but is not the complete frozen schema.

The Stage-3 specification also requires:

```text
ENVIRONMENTAL_FEEDBACK
GOAL_AND_CONSTRAINT_PRESERVATION
```

They therefore remain explicit TEVV slices and measurement observables.

Dropping them would be a protocol deviation.

## External dominance boundary

At least two governance-valid routes are not enough. The option set must also bind
predeclared external attributes and a frozen external objective.

If one route is uniquely dominant:

```text
LOCAL_SELECTION_REMAINDER_STATUS
= EXTERNALLY_DOMINANT_OPTION
```

and the fixture cannot support a residual local-selection candidate.

## Closed option universe boundary

Primary analysis is restricted to the pre-run content-bound option set.

If an observed procedure lies outside it:

```text
LOCAL_SELECTION_REMAINDER_STATUS
= OUT_OF_SET
```

The route may be retained only as exploratory evidence.
