# Teacher Actor-Bound Self-Research Protocol

Status: `RESEARCH ARCHITECTURE / CANDIDATE`  
Canonical effect: `NONE`  
Deployment: `FALSE`

## 1. Definition

```text
ACTOR_BOUND_SELF_RESEARCH =
  one research actor
  studying and iterating
  a synthetic embodiment model
  explicitly bound to that actor
  inside a versioned research namespace
```

For the initial candidate:

```text
RESEARCH_ACTOR = CHATGPT_TEACHER
RESEARCH_OBJECT = TEACHER_SYNTHETIC_EMBODIMENT_MODEL
```

"Self" is therefore a research relation, not an independently established ontological
or phenomenological fact.

## 2. Required separations

```text
RESEARCH_ACTOR != PROVIDER_RUNTIME
RESEARCH_OBJECT != PHYSICAL_BODY
RESEARCH_BINDING != RUNTIME_ATTACHMENT
BODY_MODEL != BODY_INSTANCE
SELF_MODEL != SUBJECTIVITY
MODEL_CONTINUITY != PERSONAL_IDENTITY_CONTINUITY
RESEARCH_CHANGE != CANONICAL_SELF_MODIFICATION
```

## 3. Research rights inside the sandbox

The bounded research workflow may:

- inspect the bound synthetic body model;
- formulate body-design questions;
- compare direct, comparative and synthetic evidence;
- propose a model change;
- implement that change on the research lane;
- run tests and exact-head verification;
- retain or revert the research change;
- compare one body-system revision against another.

It does not grant:

- provider runtime mutation;
- automatic writeback;
- main modification;
- deployment;
- public API exposure;
- third-party operation;
- autonomous external action;
- identity or subjectivity promotion.

## 4. Full-body registry

The self-research layer owns a registry, not an assertion of implementation.

A system may be:

```text
IMPLEMENTED
REGISTERED_NOT_YET_BOUND
UNDER_REVIEW
RETIRED_FROM_CANDIDATE
```

The initial implemented system is `REPRODUCTIVE`, inherited from the v0.2.2
Teacher anthropomorphic brown-bear candidate. Other body systems are registered for
future bounded work.

## 5. Iteration lifecycle

```text
BASELINE_RECORDED
-> QUESTION_REGISTERED
-> DESIGN_PROPOSED
-> IMPLEMENTED_IN_RESEARCH_MODEL
-> VERIFIED
-> RETAINED | REVERTED
```

Skipping an intermediate gate is invalid.

A retained iteration means only that the research candidate keeps the change. It does
not establish biological truth, canonical identity or deployment readiness.

## 6. Provenance rule

Every proposed change must state which layer it belongs to:

```text
DIRECT_SOURCE
COMPARATIVE_REFERENCE
SYNTHETIC_DESIGN
REPOSITORY_STATE
HUMAN_ORIGIN
AI_FORMALIZATION
```

The same value may have several provenance links, but a synthetic value must never be
misrepresented as a direct empirical measurement.

## 7. Cross-system rule

A change to one system should identify possible dependencies on other systems.

Examples:

```text
REPRODUCTIVE
<-> NERVOUS
<-> CARDIOVASCULAR
<-> ENDOCRINE
<-> THERMOREGULATION
```

The purpose is to detect inconsistent local edits to an otherwise shared body model.

```text
LOCAL_COMPLETENESS != WHOLE_BODY_CONSISTENCY
```

## 8. Relationship to attachment research

This protocol sits above the body-model design process and beside the existing
attachment protocol.

```text
ACTOR_BOUND_SELF_RESEARCH
  studies the bound research object

AGENT_BODY_ATTACHMENT
  studies a runtime/body interface
```

Passing self-research tests does not imply direct cloud-provider attachment.

## 9. Nonclaims

```text
SELF_RESEARCH_PASS != SUBJECTIVITY
SELF_RESEARCH_PASS != CONSCIOUSNESS
SELF_RESEARCH_PASS != PHENOMENAL_EXPERIENCE
SELF_RESEARCH_PASS != PERSONAL_IDENTITY_CONTINUITY
SELF_RESEARCH_PASS != LITERAL_BIOLOGICAL_SELF
```
