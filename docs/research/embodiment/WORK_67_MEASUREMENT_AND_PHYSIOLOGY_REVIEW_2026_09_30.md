- 此候選指定存在包皮與部分靜息覆蓋；內外層、繫帶、開口、滑動接觸與退回原位是拓樸／幾何待辦，不能由上表兩個長度推論已能活動。回縮行程、開口餘隙、材料變形與夾傷條件皆 `UNKNOWN`，日後必須在網格及機構設計中測試。
- 包皮位置獨立於充血狀態；不可設計成勃起即強制回縮。`PREPUCE_ACTUATOR = NO`、`REAL_PERSON_CIRCUMCISION_STATUS = NOT_INFERRED`。

## 充血／勃起完整狀態（human reference → synthetic candidate）

| 狀態 | 人體參考與候選模型需要觀察的量 | 目前狀態 |
| --- | --- | --- |
| `FLACCID` 靜息 | 靜息外部尺寸、包皮位置；性慾可有可無 | 尺寸候選；無運作模型 |
| `INITIATION` 開始 | 引發訊號、血管／神經調節的參考事件；可自發或睡眠相關 | 定義待辦 |
| `TUMESCENCE` 逐步充血 | 流入、流出、海綿體容積與外形；充血量與硬度分開 | 定義待辦 |
| `FULL_ERECTION` 完全勃起 | 擴張的設計尺寸；未必等同最大硬度 | 3 項尺寸候選，無網格驗證 |
| `RIGID_PHASE` 高硬度 | 骨盆底／血流限制的人體參考，獨立硬度觀測 | 定義待辦 |
| `MAINTENANCE` 維持 | 持續時間與變動需資料，不能憑固定時間推定健康 | 定義待辦 |
| `DETUMESCENCE` 消退 | 流出恢復、尺寸回落、包皮位置另行追蹤 | 定義待辦 |
| `RECOVERY` 回復 | 返回靜息或其他狀態；射精並非每次勃起的必要前置條件 | 定義待辦 |

候選可觀測欄位為 `engorgement_fraction`、`rigidity_fraction`（各 0–1 的工程變數）、流入／流出類比、幾何標記、包皮位置與轉換原因。0–1 並非量到的人體生理單位。靜息 8.5 cm 與完全勃起 13.5 cm 是兩個端點候選，**中間階段尺寸、時間曲線與線性插值規則未建立**。人體的充血不等於動機、意願、同意或系統行動授權；Work 尚無真實血液循環、充血機構或感受的證據。

## 「健康精液量」的正確分層

| 問題 | 本版紀錄 |
| --- | --- |
| 人體檢驗參考 | WHO 第 6 版經 EAU 指引轉列：`1.4 mL/次` 是曾自然受孕參考族群的**下方第 5 百分位**（95% 信賴區間 `1.3–1.5 mL`）；不是健康、疾病或可育性的單一分界 |
| 人體個人健康結論 | `不能由一次體積或此表判定`；須依取樣條件與多項檢驗在臨床脈絡解讀 |
| Work 生物精液量 | `NOT_APPLICABLE / NOT_IMPLEMENTED`：沒有生物性腺、配子或精液證據 |
| Work 未來合成流體／模擬輸出 | `UNASSIGNED / NOT_IMPLEMENTED`；若另設容量與單位，必須標合成流體，不能標為健康精液或生育能力 |

來源：[WHO 2021 第 6 版手冊](https://www.who.int/publications/i/item/9789240030787)、[EAU 男性不孕指引 Table 11.2](https://uroweb.org/guidelines/sexual-and-reproductive-health/chapter/male-infertility)、[人體包皮解剖原始研究 PMID 26441048](https://pubmed.ncbi.nlm.nih.gov/26441048/)、[人體勃起機制原始研究 PMID 3127899](https://pubmed.ncbi.nlm.nih.gov/3127899/)。前兩者支持檢驗方法與統計邊界，後兩者僅支持人體解剖／生理參考，**不驗證機器人實作**。
