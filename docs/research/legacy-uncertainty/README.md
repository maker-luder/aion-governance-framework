# 歷史分支與歸屬不確定性臨時整理線

**性質：** 暫時的 branch（分支）盤點及來源指標，不是第四個研究構念，也不是舊分支的 Git 歷史合併結果。基底為建立時的 `main` exact SHA `6a34d7780dd6d5bc717cd6c82ba39e7a6241c2fd`。

小博指定研究順位：第一，AI 主體性可能性（一直是核心，工作方向在 main）；第二，CCTS／人機學習；第三，具身獨立工作線。歸屬尚不明確的來源暫在本線列冊。見 [逐支分支處置矩陣](BRANCH_DISPOSITION_MATRIX.md)。

## 保留邊界

- 清單中的 `branch + exact head` 是來源指標；本 branch **沒有**因列出它們而包含它們的獨有提交、測試結果、審查或出版物。來源的原 ref 全部保留。
- branch 名稱可給出初步題材提示，不能證明內容歸屬或 actor。 `HOLD_UNKNOWN` 表示尚未逐 PR／逐 diff 判讀；`KEEP_ARCHIVE` 表示當時 head 是 main 祖先但引用與治理依賴尚待查。
- 本輪沒有 `SAFE_DELETE` 執行權；所有舊 branch 都不刪。小博看過最終報告並回覆後，才可另輪討論具體刪除候選。
- 任何主題研究重入須讀當時 live exact head、unique diff、PR、測試、CI、claim boundary。不得因已被列冊而宣稱內容被 main 或第二、第三線採納。

`HUMAN_ORIGIN`：小博要求不確定的來源先放第四條臨時整理線，不刪，等報告。此索引與矩陣是整理工具；不是科學驗證或 merge authority。
