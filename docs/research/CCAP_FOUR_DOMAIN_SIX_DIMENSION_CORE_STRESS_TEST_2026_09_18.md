## Purpose

can pass through the repository's existing Four-Domain admission discipline and
six standing subjectivity-relevant evidence dimensions without:

- importing a Human construct as machine ontology;
- inventing a new subjectivity dimension;
- forcing all six dimensions to appear positively relevant;
- turning structural readiness into empirical evidence;
- turning a residual source-partition classification into a model-internal locus;

## Why D2 / D3 / D5 / D6 are not opened by force

### D2 — diachronic continuity

CCAP does not yet isolate what carries a recovery tendency across time.

A future D2 test would need to distinguish at minimum:

```text
STATE_CONTINUITY
vs
MEMORY_MANIFEST_CONTINUITY
vs
RETRIEVAL_RECONSTRUCTION
vs
ARTIFACT_HISTORY
vs
PROMPT_REINTRODUCTION
```

### D3 — self-model causal role

No current CCAP result manipulates a self-model as an independent causal variable.

A future D3 test requires matched:

```text
SELF_MODEL_PRESENT
SELF_MODEL_ABLATED
SELF_MODEL_INTERVENED
```

with external conditions held constant.

### D5 — counterfactual self-consistency

The current replay/order controls are not a full counterfactual self-consistency test.

A future D5 design must predeclare what self-consistency property should survive a
counterfactual perturbation and what simpler prompt/context consistency explanation
would falsify the stronger interpretation.

### D6 — constitution / integration consequence

Configuration change is not constitution change.

A future D6 test would need to show that manipulating a candidate state has a
consequential effect on the system's own organization / integration rather than merely
changing an externally supplied configuration.

```text
CONFIGURATION_CHANGE
!= SELF_CONSTITUTION_CHANGE

STATE_EFFECT
!= CONSTITUTIONAL_INTEGRATION
```
