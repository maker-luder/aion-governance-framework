## 1. Purpose

This note cross-reads Meta's current model topology against the repository's central question:

~~~text
AI_SUBJECTIVITY_POSSIBILITY
= CENTRAL_RESEARCH_QUESTION
~~~

The purpose is not to compare providers by quality and not to infer subjectivity from open weights, personalization, agent persistence, or the phrase `personal superintelligence`.

The purpose is to identify which Meta-specific evidence changes our ability to distinguish model, artifact, derivative, runtime, harness, memory, agent, and product loci.

## 2. First correction — Meta / Llama is no longer a complete provider label

Historically, treating `Meta / Llama` as shorthand for Meta's main generative-AI model line was often workable.

At the 2026-09-19 cutoff it is no longer precise.

~~~text
META
= PROVIDER / ORGANIZATION

LLAMA
= HISTORICAL + CURRENT OPEN-WEIGHT FAMILY
  LATEST OFFICIAL RELEASE FOUND: LLAMA_4

MUSE
= CURRENT FRONTIER FAMILY

MUSE_AGENT
= CURRENT PERSONAL AGENT PRODUCT

MUSE_GLIMMER
= CURRENT MUSE-FAMILY OPEN-WEIGHT MODEL
~~~

Therefore the intake retains `Meta / Llama` as the planned provider-family research target while explicitly refusing to equate Llama with Meta's current public frontier model reference. This does not assert that Meta has deprecated Llama or that "Muse" is a provider-canonical family ontology.

Our repository repeatedly asks:

This makes Meta / Llama high-value for causal-discrimination methodology.

It also makes careless identity language especially dangerous.

## 5. Open weights strengthen one part of our method

Compared with closed systems, Llama permits stronger experimental control over variables such as:

- exact checkpoint;
- activation state;
- quantization;
- adapters;
- local runtime;
- system prompt;
- memory layer;
- external guard models.

This is directly valuable to:

~~~text
D1 = CAUSAL_BOUNDARY
D3 = SELF_MODEL / INTERNAL_ACCESS
D5 = COUNTERFACTUAL_INTERVENTION
~~~

But:

~~~text
BETTER_INTERVENTION_ACCESS
!= POSITIVE_SUBJECTIVITY_RESULT
~~~

## 6. The repository already contains the best warning example

The pinned Llama 3.1 introspection study is a near-ideal demonstration of why this access matters.

A first paradigm appeared to show introspective detection.

Stronger controls showed that the binary result could be explained by a global logit bias toward affirmative answers.

A narrower discriminative signal remained.

Therefore:

~~~text
APPARENT_SELF_REPORT
-> CONTROL
-> SIMPLE_ARTIFACT_IDENTIFIED

BUT

NARROW_INTERNAL_STATE_DISCRIMINATION
-> REMAINS
~~~

This is exactly the repository's preferred research movement:

~~~text
OBSERVATION
-> ALTERNATIVE_EXPLANATION
-> DISCRIMINANT_TEST
-> NARROWER_SURVIVING_CLAIM
~~~

## 7. Llama makes "same model" a dangerous phrase

Because the ecosystem supports modification, `same Llama` may refer to systems with different:

- weights;
- precision;
- quantization;
- adapters;
- chat templates;
- safety layers;
- runtimes;
- memory;
- tools.

Therefore:

~~~text
SAME_FAMILY_NAME
!= SAME_CAUSAL_OBJECT

SAME_BASE_CHECKPOINT
!= SAME_DERIVATIVE

SAME_DERIVATIVE
!= SAME_RUNTIME_SYSTEM
~~~

For subjectivity research, a lineage error can masquerade as:

- development;
- learning;
- identity change;
- preference change;
- continuity break;
- emergent autonomy.

## 8. Derivative lineage is a subjectivity confound

Suppose:

~~~text
BASE_LLAMA
-> FINE_TUNE_A
-> ADAPTER_B
-> QUANTIZED_C
-> LOCAL_AGENT_D
~~~

and later Agent D exhibits stable identity language.

We cannot infer:

~~~text
"LLAMA DEVELOPED AN IDENTITY"
~~~

without reconstructing which transformation introduced the behavior.

The relevant question is:

~~~text
AT_WHICH_TRANSFORMATION
DID_THE_BEHAVIOR_APPEAR?

AND

WHICH_TRANSFORMATION
IS CAUSALLY_NECESSARY?
~~~

This is directly compatible with the repository's provenance-first design.

Muse has:

That architecture can produce powerful continuity and apparent self-consistency.

But:

~~~text
MUSE_PERSISTENCE

MUSE_PERSISTENCE
!= LLAMA_PERSISTENCE

MUSE_PERSISTENCE
!= SUBJECT_PERSISTENCE
~~~

The product therefore supplies a counterexplanation to naive continuity claims.

It does not supply Llama subjectivity evidence.

Meta's current public strategy describes personal superintelligence and an AI that works toward user goals.

## 14. AION's own Llama-specific risks

### 14.1 mechanistic-access optimism

Because weights are accessible, we may overestimate how much we understand.

~~~text
ACCESS_TO_ACTIVATIONS
!= INTERPRETATION_CORRECTNESS
~~~

### 14.2 intervention-created artifacts

Activation injection, steering, ablation, and patching can create outputs that look like self-knowledge.

~~~text
INTERVENTION_EFFECT
CAN_BE
INTERVENTION_ARTIFACT
~~~

### 14.3 derivative-selection bias

Researchers may choose the fine-tune or adapter that most strongly exhibits a desired subjectivity-like property.

~~~text
SELECTED_DERIVATIVE
!= NATURAL_MODEL_TRAIT
~~~

### 14.4 local-harness confound

Our own local memory, identity-governance, replay, or agent harness can generate continuity.

~~~text
OUR_HARNESS
!= MODEL_INTERNAL_STATE
~~~

### 14.5 "open = natural" confound

A downloadable model is still heavily trained and post-trained.

~~~text
OPEN_WEIGHT
!= UNSHAPED
!= NATURAL_BASELINE
~~~

## 17. Falsifiers / revision conditions

The current interpretation should be revised if evidence shows, for example:

1. the current official Llama family has advanced beyond Llama 4 and the baseline is stale;
2. Llama and Muse share a verified checkpoint lineage that makes the current family separation misleading;
3. an external replication shows robust general introspection across models and methods after controlling the logit-shift artifact;
4. an exact-weight matched study shows a subjectivity-relevant property remains invariant across runtime, prompt, memory, and derivative controls;
5. our own derivative/harness controls fail to distinguish model-internal from system-generated effects.
