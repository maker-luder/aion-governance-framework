## 5. Candidate temporal CCTS model

Let `P(t)` denote the explicit problem representation at time `t`.

```text
P(t)

+ Human contribution
+ AI contribution
+ external evidence
+ repository evidence
+ implementation evidence

-> mismatch / challenge / counterevidence
-> reciprocal revision
-> P(t+1)
-> persistent artifact
-> session boundary
-> re-entry
-> P(t+n)
-> held-out transfer test
```

The candidate observation target is not merely whether text changed, but whether a problem representation changed in a persistent and discriminable way.

## 6. Primary research question

> Under matched-information conditions, does repeated evidence-sensitive Human-AI reciprocal revision produce persistent and transferable changes in explicit problem representation that cannot be adequately explained by lexical reuse, repeated exposure, retrieval, context persistence, model-version change, or Human practice alone?

## 7. Candidate discriminants and falsifiers

A later implementation should distinguish at minimum:

```text
TEXT_CHANGED
!= PROBLEM_REPRESENTATION_CHANGED

LEXICAL_REUSE
!= CONCEPTUAL_TRANSFER

CCTS_PRESENT
!= HUMAN_LEARNING_ESTABLISHED

JOINT_PERFORMANCE_GAIN
!= HUMAN_INDEPENDENT_GAIN

REPOSITORY_REENTRY
!= INTERNALIZED_SKILL

REPEATED_EXPOSURE
!= RECIPROCAL_REVISION_EFFECT
```

Candidate falsifiers / weakening conditions include:

1. matched one-way assistance performs equivalently to reciprocal revision;
2. apparent persistence disappears when repository/retrieval support is removed;
3. held-out transfer fails despite apparent within-session improvement;
4. change is explainable by lexical reuse alone;
5. a fresh context with matched information reconstructs the same state at comparable cost;
6. Human independent performance degrades while joint performance improves;
7. model-version or prompt-context changes explain the apparent trajectory;
8. removing challenge / counterevidence does not alter the observed effect.

The structural resemblance does not establish mechanistic identity.

```text
BODY_SCHEMA_ADAPTATION
!= EPISTEMIC_SCHEMA_ADAPTATION

STRUCTURAL_ANALOGY
!= SAME_MECHANISM

!= CCTS

!= EMBODIMENT

```

A future embodied CCTS study would therefore require a distinct cross-layer design and fresh authorization. Existing closed embodiment PRs remain closed.
