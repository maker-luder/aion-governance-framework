## Restart rule

There is no automatic restart.

A future GitHub cycle requires all of the following:

1. new explicit Human Owner authorization;
2. fresh branch/PR/issue/release/workflow inventory;
3. fresh ChatGPT architecture/evidence/provenance review;
4. explicit scope and resource budget;
5. explicit decision on whether any historical candidate is merely referenced, newly resumed, or newly promoted.
