# Maintenance records

This directory contains additive records for bounded external maintenance performed after repository freeze / project termination. These records document preservation or hardening work only.

```text
PROJECT_RESTART = NO
RESEARCH_RESTART = NO
CANONICAL_EFFECT = NONE
DEPLOYMENT = FALSE
RETROACTIVE_HISTORY_REWRITE = FORBIDDEN
```

Maintenance evidence does not supersede dated historical governance records, scientific non-claims, or the preserved whitepaper lineage.
