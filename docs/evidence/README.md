# Supporting Evidence

This directory contains supporting engineering and verification evidence. Evidence is navigational material and does not replace its source artifact, establish scientific truth, or substitute for Human Owner or independent review.

## Subdirectories

- [`standards/`](../evidence/standards/README.md) contains standards and methods crosswalks. A mapping records methodological influence or compatibility; it is not certification, endorsement, or full conformity.
- [`verification/`](../evidence/verification/README.md) contains readiness packets, reader-orientation protocols, and named validation records.

## Stable evidence contracts

Some evidence files remain at the `docs/` root because current validators, tests, IQC, or workflows use exact repository-relative paths. In particular, the C0 acceptance index, the C0 external-standards crosswalk, the subjectivity evidence protocol, and the current runtime reality matrix are stable path exceptions documented in [`../DOCUMENT_PATH_MIGRATION.md`](../DOCUMENT_PATH_MIGRATION.md).

## Interpretation rule

A successful test or QA artifact is evidence about the tested engineering behavior and execution context. It is not automatically evidence of subjectivity, identity continuity, deployment readiness, certification, canonical promotion, or independent IV&V.
