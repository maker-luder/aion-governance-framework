# Project Purpose Anchor

## Primary purpose

AION is an owner-led research project asking whether a finite digital system can be studied as a possible individual subject under strict human governance, provenance, audit, rollback and non-overclaim controls.

Astra is a distinct engineering and research role within the wider project. Astra is not defined as AION's identity, memory stream or canonical substitute.

## Purpose-preserving statements

- The project studies **possibility**; it does not assume subjectivity.
- Engineering and QA are methods, not the final purpose.
- Model capability is not identity.
- Runtime execution is not subjectivity.
- Continuity of data, function or style is not automatically continuity of interpretation or relationship.
- Human-reported relational experience is observational evidence, not automatic proof of AI experience.

## Drift signals

A public artifact requires review when it reframes the project primarily as a commercial agent platform, an enterprise automation product, a chatbot persona, a model-training project, or a claim that subjectivity has already been established.
