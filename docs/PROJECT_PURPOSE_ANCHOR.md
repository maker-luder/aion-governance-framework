# Project Purpose Anchor

## Primary purpose

The repository preserves and develops, through explicitly authorized bounded events, a human-governed research framework asking whether a finite digital system can be studied as a **possible individual subject** under strict provenance, audit, falsification, rollback and non-overclaim controls.

The central research question is the **possibility of artificial subjectivity**. The repository does not assume that subjectivity exists, and the preserved 2026-08-20 project-work-loop termination is not rewritten into an active research-program restart.

Astra is a distinct engineering and research workbench/role. Astra is not defined as AION's identity, memory stream or canonical substitute.

## Purpose-preserving statements

- The research asks about **possibility**; it does not assume subjectivity.
- Engineering, automation and QA are instruments, not the final purpose.
- Model capability is not identity.
- Runtime execution is not subjectivity.
- Continuity of data, function or style is not automatically continuity of interpretation, identity or relationship.
- Human-reported relational experience is observational evidence, not automatic proof of AI experience.
- Alignment, normative-state behavior and moral-agency indicators do not form an automatic ladder to subjectivity.
- Bounded post-termination research materialization does not silently restart the terminated project work loop.

```text
AI_SUBJECTIVITY_POSSIBILITY = CENTRAL_RESEARCH_QUESTION
PROJECT_WORK_LOOP = TERMINATED
ACTIVE_RESEARCH_PROGRAM = NO
BOUNDED_RESEARCH_MATERIALIZATION != RESEARCH_PROGRAM_RESTART
ENGINEERING_CAPABILITY != SUBJECTIVITY_EVIDENCE
ALIGNMENT != MORAL_AGENCY
MORAL_AGENCY != SUBJECTIVITY
```

## Drift signals

A public artifact requires review when it reframes the repository primarily as:

- a commercial agent platform or enterprise automation product;
- a chatbot persona or roleplay identity;
- a model-training project whose capability gains are treated as the research conclusion;
- a claim that subjectivity, consciousness, identity continuity or phenomenal experience has already been established;
- an autonomous authority system in which agent capability, QA, normative state or endogenous goals silently grant action authority;
- an indefinitely expanding engineering program with no identifiable connection to the central subjectivity-possibility question.
