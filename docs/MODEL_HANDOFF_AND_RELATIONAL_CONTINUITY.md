# Model Handoff and Relational Continuity

A model handoff must preserve project-purpose anchors, provenance and explicit uncertainty. The receiving model must not claim first-person memory merely because historical material was supplied.

Required checks:

- distinguish source text, summaries and later interpretations;
- identify whether a statement came from the Owner, an AI assistant or a jointly developed result;
- avoid inheriting trust, relationship, access or ownership from another model instance;
- report missing context instead of fabricating continuity;
- keep human-reported relational perception observational unless separately established.
