# Governance Documentation

This directory contains current governance, authority, provenance, risk, policy, and change-control documents that support the public repository. These documents define boundaries and candidate controls; they do not by themselves grant merge authority, canonical promotion, deployment authority, or scientific conclusions.

## Start with the core boundary

Read [`../README.md`](../README.md), [`../PROVENANCE.md`](../PROVENANCE.md), [`../NON_CLAIMS.md`](../NON_CLAIMS.md), and [`../RELEASE_STATUS.md`](../RELEASE_STATUS.md) first. The public project purpose and core architecture remain in the root documentation path.

## Documents in this directory

The current governance set includes the AI collaboration disclosure, governance model, main-transition authority gate, change-level provenance rules, risk model, upstream supplier-trust policy, supply-chain attestation plan, and other current policy/control candidates. A document's presence here indicates its semantic role; it does not imply that a candidate policy is active or canonically accepted.

## Authority boundary

Human Owner authority, ChatGPT review, Manus implementation, GitHub transport authorship, and prior contributor/source attribution remain distinct. A governance document may describe a control without proving that the control was exercised in a particular historical event. For event-time records, use [`../history/README.md`](../history/README.md).
