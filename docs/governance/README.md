# Governance Documentation

This directory contains current governance, authority, provenance, risk, policy, and change-control documents that support the public repository. These documents define boundaries and candidate controls; they do not by themselves grant merge authority, canonical promotion, deployment authority, or scientific conclusions.

## Start with the core boundary

Read [`../README.md`](../README.md), [`../PROVENANCE.md`](../PROVENANCE.md), [`../NON_CLAIMS.md`](../NON_CLAIMS.md), and [`../RELEASE_STATUS.md`](../RELEASE_STATUS.md) first. The public project purpose and core architecture remain in the root documentation path.

## Documents in this directory

The current governance set includes the AI collaboration disclosure, governance model, main-transition authority gate, change-level provenance rules, risk model, upstream supplier-trust policy, supply-chain attestation plan, and other current policy/control candidates.

The candidate [`CHATGPT_RESEARCH_STEWARDSHIP_AND_SUBJECTIVITY_CORE_RULE.md`](CHATGPT_RESEARCH_STEWARDSHIP_AND_SUBJECTIVITY_CORE_RULE.md) records a bounded OpenAI ChatGPT research-steward role: candidate contribution is permitted, main-merge execution is permitted only when deliberative progress, subjectivity-core preservation, provenance, and all active main-transition controls are satisfied. It explicitly preserves AI subjectivity as an open research possibility rather than a precommitted conclusion.

The candidate [`GOVERNED_KNOWLEDGE_SOURCE_REGISTRY.md`](GOVERNED_KNOWLEDGE_SOURCE_REGISTRY.md) defines bounded, provenance-bearing source admission and retrieval for AION / Astra. It separates source-declared status from AION canonical authority, requires hard context caps, records shared-source exposure for independence claims, and treats the Human Owner's 2026-08-27 11-source map as metadata-only until the underlying materials are supplied and verified.

A document's presence here indicates its semantic role; it does not imply that a candidate policy is active or canonically accepted.

## Authority boundary

Human Owner authority, ChatGPT review, Manus implementation, GitHub transport authorship, and prior contributor/source attribution remain distinct. A governance document may describe a control without proving that the control was exercised in a particular historical event. For event-time records, use [`../history/README.md`](../history/README.md).
