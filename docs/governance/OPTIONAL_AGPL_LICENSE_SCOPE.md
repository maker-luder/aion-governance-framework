receiving an explanation of source-sharing obligations. This supersedes only the
earlier decision to hold public Swiss integration in the
[local-trial record](../research/SWISS_EPHEMERIS_LOCAL_TRIAL_2026_09_03.md).

| Material | License / disposition |
|---|---|
| Existing AION core and pre-existing Apache-2.0 original code | Original Apache-2.0 grant and notices preserved |

| Research texts and other third-party material | Their existing separately recorded terms remain in force |

The [official upstream licensing statement](https://www.astro.com/swisseph/swephinfo_e.htm)
offers AGPL and professional routes. The [AGPL text](https://spdx.org/licenses/AGPL-3.0-only.html)
governs copying, modification, corresponding source and applicable network-user
access. The optional adapter is published as source with packaging instructions,
tests, AGPL text and preserved upstream notices. It acquires unmodified native
files directly from upstream rather than redistributing a native binary bundle.

Do not infer that separate folders, subprocesses or an API automatically exempt
a combined product from copyleft. The optional dependency is not imported by the
core, and the core remains usable without it. If a future change combines the
works more tightly or serves a modified version over a network, reassess the
whole distribution/service and provide required corresponding source access.
No public service, release certification or universal legal compliance claim is
created by this engineering change.

Private input data are distinct from program source. Do not publish personal
birth details, credentials, conversations or lost-source reconstructions as a
supposed licensing requirement. The Owner's existing learning context remains
an attributed, bounded reference.
