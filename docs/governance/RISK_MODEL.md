# Risk Model

Risk categories include:

- execution and tool misuse;
- filesystem, network and credential exposure;
- identity, lineage and fork confusion;
- memory poisoning and cross-namespace leakage;
- evidence fabrication, suppression or provenance loss;
- interpretation drift and purpose inversion;
- relational trust exploitation and authorization confusion;
- overclaiming subjectivity, validation, certification or deployment status.

Controls include default-deny policies, bounded scopes, human approval, audit records, immutable hashes, tombstones, conflict states, stop conditions, rollback and public/private separation.
