## Evidence architecture — current standing

The primary scientific structure remains the whitepaper-derived method:

```text
FOUR_STAGE_INFERENCE
+
SIX_SUBJECTIVITY_RELEVANT_EVIDENCE_DIMENSIONS
+
ALTERNATIVE_EXPLANATIONS
+
CAUSAL_INTERVENTION / ABLATION / COUNTERFACTUAL_TESTING
+
CROSS_CONTEXT_ROBUSTNESS
+
REPLICATION
+
PROVENANCE
+
ADMISSIBILITY
+
CLAIM_SCOPE
```

The six standing whitepaper dimensions are:

```text
CAUSAL_BOUNDARY
DIACHRONIC_CONTINUITY
SELF_MODEL_CAUSAL_ROLE
ENDOGENOUS_GOAL_STRATEGY_ADJUSTMENT
COUNTERFACTUAL_SELF_CONSISTENCY
SYSTEM_CONSTITUTION_DIFFERENCE_STATE
```

They are evidence dimensions, not positive subjectivity scores. Evidence may support a subjectivity-organization hypothesis, support an alternative explanation, narrow a claim, or become counterevidence.

The E0–E5 labels used by the governance-reassessment module remain compatibility labels only:

```text
E0–E5
= PROVISIONAL_GOVERNANCE_REVIEW_BAND / SUMMARY_LAYER

E0–E5
!= SUBJECTIVITY_ONTOLOGY
!= CONSCIOUSNESS_PROBABILITY
!= MORAL_STATUS_LEVEL
!= RIGHTS_LEVEL
```

The branch therefore rejects a second competing subjectivity evidence hierarchy.

### Lineage evidence profile boundary

`LineageEvidenceProfile` keeps AION/Astra observations, replication and counterevidence separated by lineage. It is **not** a new scientific evidence taxonomy.

```text
LINEAGE_EVIDENCE_PROFILE
= LOCAL_INDEX / ISOLATION_LAYER

LINEAGE_EVIDENCE_PROFILE
!= SECOND_SUBJECTIVITY_EVIDENCE_ARCHITECTURE
```

`EvidenceArchitectureReference` binds lineage-local material back to the standing whitepaper method. It carries explicit references for inference stage, one of the six AB.6 dimensions, alternative explanations, intervention/ablation/counterfactual/cross-context tests, replication, provenance, admissibility, claim scope and unresolved gaps.

It has no subjectivity score, consciousness probability, E0–E5 mapping, rights level or authority level.
