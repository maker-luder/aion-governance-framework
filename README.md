AION is a human-governed, provenance-first, auditable research framework for studying the **possibility of artificial subjectivity** without treating convincing behavior, memory-like continuity, relationship language, or successful software tests as proof that subjectivity exists.

Its central question is methodological: **what evidence is relevant, how strong may a claim become, and how can the research process remain auditable when identity, continuity, memory, Human–AI interaction, and long-horizon AI behavior are being studied?**

Astra is a distinct engineering and research workbench used to materialize and test bounded candidates. It is not defined as AION's identity, memory stream, or substitute for subjectivity.

```text
AI_SUBJECTIVITY_POSSIBILITY = CENTRAL_RESEARCH_QUESTION
SCIENTIFIC_DISPOSITION = HOLD
SUBJECTIVITY = NOT_ESTABLISHED
CONSCIOUSNESS = NOT_ESTABLISHED
PHENOMENAL_EXPERIENCE = NOT_ESTABLISHED
```

## What this repository is for

The repository keeps observation, evidence, inference, hypothesis, implementation, authority, and scientific conclusion separate so that a plausible interpretation cannot silently become a fact merely because software exists or interaction feels continuous.

It currently contains bounded work on:

- subjectivity-relevant evidence methods and explicit non-claims;
- identity, continuity, memory, and provenance;
- Human–AI longitudinal research and interaction-history study surfaces;
- bounded synthetic experiments and deterministic research harnesses;
- research-quality, QA/QC, exact-head, and NCR/CAPA controls.

Important boundaries include:

```text
ENGINEERING_CAPABILITY != SUBJECTIVITY_EVIDENCE
HUMAN_AI_LEARNING != AI_SUBJECTIVITY
RELATIONAL_CONTINUITY != AI_IDENTITY_CONTINUITY
HARNESS_PASS != HYPOTHESIS_CONFIRMED
CI_PASS != SCIENTIFIC_VALIDATION
```

These boundaries do not pre-decide the research question. They prevent stronger conclusions from being claimed than the available evidence supports.

## Governance and license

AION remains human-governed. Engineering capability, automation, quality checks, AI review, or prior approval do not independently create authority to transition `main`.

```text
QA_PASS != MERGE_APPROVAL
AI_REVIEW != HUMAN_OWNER_MERGE_APPROVAL
AUTONOMOUS_MERGE = NO
AUTONOMOUS_REPOSITORY_WRITEBACK = NO
```

The core repository remains Apache-2.0. The optional [`Swiss Ephemeris example`](examples/swiss-ephemeris-agpl_v0.1.0/README.md) is AGPL-3.0-only, so the repository should not be described as uniformly Apache-only.
