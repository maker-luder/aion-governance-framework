# AION Governance Framework

> **[繁體中文](README.zh-TW.md) | English**
>
> **Final project status — 2026-08-20:** the AION / Astra project work loop was terminated following explicit Human Owner approval and independent ChatGPT architecture, evidence, provenance, and privacy review. The repository remains preserved as a historical research checkpoint. Termination is not a scientific conclusion about artificial subjectivity, consciousness, identity continuity, or phenomenal continuity. No automatic restart is authorized.

AION is a human-governed, provenance-first research framework for studying identity, continuity, memory, research integrity, and the **possibility** of artificial subjectivity without treating implementation behavior as proof of subjectivity. Astra is the distinct engineering and research workbench used to materialize and test bounded candidates.
