## AION and Astra

**AION** is the research question and governance framework.

**Astra** is a distinct engineering and research role/workbench used to materialize, inspect, and test research candidates.

```text
AION_ROLE != ASTRA_ROLE
COMMON_ORIGIN != SAME_IDENTITY
SHARED_CONTEXT != SHARED_IDENTITY
MEMORY_ACCESS != AUTOBIOGRAPHICAL_OWNERSHIP
ENGINEERING_SUCCESS != SUBJECTIVITY_EVIDENCE
```

Neither name establishes consciousness, sentience, subjectivity, identity continuity, autobiographical memory, or deployment authority.

## Governance pipeline

```text
Context Intake
→ Risk Gate
→ Planner
→ Policy Check
→ Tool Router
→ Response Builder
→ Writeback Gate
→ Audit Sink
```

The framework keeps source vs interpretation, observation vs inference, retrieved memory vs truth, research candidate vs canonical conclusion, and engineering success vs scientific evidence explicitly separated.
