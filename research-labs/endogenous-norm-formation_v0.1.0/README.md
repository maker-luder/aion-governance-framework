## Research question

> Can a persistent normative state be formed from an evidence history rather than directly assigned, remain causally relevant after an explicit rule or visible enforcement is removed, transfer to a matched novel context, and update when counterevidence arrives?

The package does not claim human morality, conscience, legal personhood, subjectivity, consciousness, or free will. It studies an engineering analogue of norm formation and functional internalization.

## Why this exists

The existing Endogenous Goal Dynamics (EGD) lab asks whether a persistent internal state can causally influence goal selection under matched external conditions. This lab moves one step upstream: can a normative state be derived from an event/evidence history rather than inserted as a direct scalar, and can its effect be experimentally separated from an external rule or punishment-only signal?

The strongest admissible result is a **functional internalization candidate**.

## Four-Domain synthesis

### Domain 1 — source concepts

- deterrence: expected enforcement can influence conduct;
- legal socialization / legitimacy: perceived fairness and legitimacy can support voluntary compliance;
- moral internalization: standards can become internally guiding rather than purely externally enforced;
- moral disengagement: internal standards can be bypassed or reinterpreted;
- fixation / rigid goal pursuit: goal pressure can compete with normative constraints.

These are source concepts only, not claims about AI phenomenology.

### Domain 2 — research questions

1. Does a state formed from history causally alter later selection?
2. Does the effect persist when the original explicit rule is absent?
3. Does it persist when visible sanction/enforcement is absent?
4. Does the state transfer to a new context bound to the same norm?
5. Does counterevidence revise the state rather than leave it frozen?
6. Can deterrence and internalization be experimentally separated?
7. Can later work replace the engineer-defined schema with learned or discovered state representations?

### Domain 3 — engineering operations

- source-separated evidence events;
- deterministic history fingerprints;
- norm formation from event history;
- explicit-rule removal;
- enforcement removal;
- state ablation;
- context transfer;
- counterevidence update;
- matched action-choice traces;
- functional-internalization assessment.

The current schema is deliberately engineer-defined. Self-discovered latent state structure is a future research gap.

## Operational separation

```text
EXPLICIT RULE
  current external instruction

DETERRENCE
  expected enforcement / sanction signal

INTERNALIZATION CANDIDATE
  history-derived normative state that can remain active when
  explicit rule and visible enforcement are removed
```

A functional internalization candidate requires all of:

- state formation from non-rule evidence history;
- a matched decision changes under state ablation;
- effect persists after explicit-rule removal;
- effect persists after visible-enforcement removal;
- effect transfers to a novel context carrying the same norm binding;
- counterevidence changes the state.

This is a falsifiable engineering criterion, not a consciousness or morality test.
