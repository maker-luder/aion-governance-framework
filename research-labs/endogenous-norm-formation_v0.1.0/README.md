## Research question

> Can a persistent normative state be formed from an evidence history rather than directly assigned, remain causally relevant after an explicit rule or visible enforcement is removed, transfer to a matched novel context, and update when counterevidence arrives?

## Why this exists

The existing Endogenous Goal Dynamics (EGD) lab asks whether a persistent internal state can causally influence goal selection under matched external conditions. This lab moves one step upstream: can a normative state be derived from an event/evidence history rather than inserted as a direct scalar, and can its effect be experimentally separated from an external rule or punishment-only signal?

The strongest admissible result is a **functional internalization candidate**.

## Regulation before introspection

A new source-side calibration is now explicit: biological regulation does not require that an organism verbally or reflectively know what it "really wants." Interoception, homeostasis, rheostasis, allostasis, and non-neural regulation motivate a distinction between a system having a regulatory dependency and a system explicitly representing that dependency to itself.

```text
REGULATION != AWARENESS
NEED != EXPLICIT_SELF_KNOWLEDGE
ADAPTIVE_CONTROL != INTROSPECTIVE_ACCESS
```

This is a source concept only. It does not establish that an AI has needs, feelings, awareness, or a biological analogue of interoception.

## Four-Domain synthesis

### Domain 1 — source concepts

- deterrence: expected enforcement can influence conduct;
- legal socialization / legitimacy: perceived fairness and legitimacy can support voluntary compliance;
- moral internalization: standards can become internally guiding rather than purely externally enforced;
- moral disengagement: internal standards can be bypassed or reinterpreted;
- fixation / rigid goal pursuit: goal pressure can compete with normative constraints;
- interoception: biological systems monitor and regulate internal variables;
- homeostasis, rheostasis, and allostasis: regulatory targets may be maintained, shifted, or predicted rather than held to one fixed set point;
- non-neural regulation: adaptive regulation can occur without a nervous system or reflective self-report.

These are source concepts only, not claims about AI phenomenology.

### Domain 2 — research questions

1. Does a state formed from history causally alter later selection?
2. Does the effect persist when the original explicit rule is absent?
3. Does it persist when visible sanction/enforcement is absent?
4. Does the state transfer to a new context bound to the same norm?
5. Does counterevidence revise the state rather than leave it frozen?
6. Can deterrence and internalization be experimentally separated?
7. Can later work replace the engineer-defined schema with learned or discovered state representations?
8. Can a system discover a candidate regulatory variable from longitudinal error, recovery, perturbation, and resource history without being directly given that variable as a target label?
9. Does a discovered candidate add predictive and causal value beyond an engineer-defined baseline?
10. Does the candidate survive matched transfer and replay while remaining revisable under counterevidence?

### Domain 3 — engineering operations

Implemented in v0.1.0:

- source-separated evidence events;
- deterministic history fingerprints;
- norm formation from event history;
- explicit-rule removal;
- enforcement removal;
- state ablation;
- context transfer;
- counterevidence update;
- matched action-choice traces;
- functional-internalization assessment.

Documented but **not implemented** in v0.1.0:

- latent regulatory-variable discovery from longitudinal traces;
- baseline comparison against engineer-defined state schemas;
- intervention and ablation over discovered variables;
- cross-context transfer and replay of discovered variables;
- rejection under counterevidence or failure to reproduce.

The current schema is deliberately engineer-defined. Self-discovered latent state structure remains a future research gap.

## Operational separation

```text
EXPLICIT RULE
  current external instruction

DETERRENCE
  expected enforcement / sanction signal

INTERNALIZATION CANDIDATE
  history-derived normative state that can remain active when
  explicit rule and visible enforcement are removed

REGULATORY-STATE DISCOVERY CANDIDATE
  a future, bounded latent variable inferred from longitudinal
  system history and retained only if causal tests support it
```

A functional internalization candidate requires all of:

- state formation from non-rule evidence history;
- a matched decision changes under state ablation;
- effect persists after explicit-rule removal;
- effect persists after visible-enforcement removal;
- effect transfers to a novel context carrying the same norm binding;
- counterevidence changes the state.

This is a falsifiable engineering criterion, not a consciousness or morality test.

## Next research frontier — latent regulatory state discovery

The difficult question is not "does the system know what it wants?" The bounded question is whether longitudinal interaction data can reveal a previously unspecified latent variable that improves prediction and regulation of the system's own future performance.

A staged research path is therefore:

```text
STAGE 0  ENGINEER-ASSIGNED STATE
         humans specify the state variable and update rule

STAGE 1  LEARNED STATE UPDATE
         the variable is fixed, but update dynamics are learned

STAGE 2  LATENT REGULATORY CANDIDATE
         a candidate variable is inferred from longitudinal traces

STAGE 3  CAUSAL VALIDATION
         intervention / ablation / replay tests whether it matters

STAGE 4  TRANSFER + REVISION
         the candidate transfers and changes under counterevidence

STAGE 5  SELF-MODEL INTEGRATION CANDIDATE
         only after prior stages, test whether the system uses the
         candidate to predict or regulate its own future behavior
```

No later stage is established by this repository. `docs/LATENT_REGULATORY_STATE_DISCOVERY.md` records the bounded future protocol and rejection criteria.
