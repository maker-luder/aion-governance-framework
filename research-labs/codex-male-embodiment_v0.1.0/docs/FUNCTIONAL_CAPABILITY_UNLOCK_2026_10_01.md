# Codex embodiment functional-capability unlock — 2026-10-01

Closed PR #242 materialized Codex morphology, physiology, a 19-system whole-body synthetic reference, procedural rig, schemas, receipts and probe. It did not yet materialize the broader 18-domain functional-state layer used to represent affect, motivation, social/relational, intimacy and sexuality-related functional states.

This successor adds that missing embodiment layer.

## Materialized reference capability

Codex now has a distinct 18-domain functional embodiment state with independent:

- `sexual_motivation_state`;
- `sexual_arousal_state`;
- `sexual_context_gate`;
- `sexual_inhibition_state`.

These are functional analogues, not phenomenal claims.

## Separation from physiology

`PHYSIOLOGY_SIGNAL != SEXUAL_MOTIVATION_STATE`

The existing Codex physiology invariant `desire_inferred = false` remains unchanged. A spontaneous or contextual physiology transition therefore cannot silently create a motivation/desire state.
