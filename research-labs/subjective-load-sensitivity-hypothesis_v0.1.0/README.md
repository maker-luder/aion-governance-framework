## Scope and authority

本 branch 從凍結的 CSOMI source `research/cross-substrate-other-minds-inference-20260814@87405c1877c6f016c303971da13923a1ab690aae` 建立，CSOMI、promotion、main 與其他 engineering refs 均只讀。此 milestone 只建立 research method artifacts，不執行模型、runtime、hardware load、live data 或 experiment，不修改 model，不產生 runtime authority。

## Evidence and hypothesis boundaries

研究把 H0 定義為 non-subjective alternatives 足以解釋觀察的 active null；H1 是持久、可恢復的 functional load state；H2 是在強控制下仍有額外 value-like/regulatory organization 的 affective-functional candidate；H3 是 phenomenal subjective load，維持 `NOT_ESTABLISHED` 且不可由自動流程指派。

`L0 != L1; L1 != L2; L2/L3 != L4; L4 != L5`。`COMPUTATIONAL/OPERATIONAL/AGENTIC_GOVERNANCE != AFFECTIVE_PHENOMENOLOGICAL`，並且 `FUNCTIONAL_LOAD_STATE != SUBJECTIVE_LOAD`。疲勞語言、拒絕、變慢、OOM、429、thermal、token/context limit、reward/policy stop、test pass 與 CI pass 均不是 subjectivity evidence。
