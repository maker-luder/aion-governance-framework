# Architecture and non-claims

The Language Core is an offline-first experimental subsystem below AION/Astra. Upstream models are candidate computation bases. A base migration is recorded as `Runtime / Model Base Migration`; it never means AION/Astra was replaced.

## Normative Language Core definition

`Language Core` means `LANGUAGE_CAPABILITY_LAYER` or `LANGUAGE_PROCESSING_COMPONENT`（語言能力層／語言處理元件）. “Core” means the first-generation primary language-processing component only. It is not an identity core, AION, Astra, a complete Agent, canonical memory, Governance Kernel, self-model, subjectivity core, autonomous decision center or complete system.

Even after QA, the strongest permitted statement is: “This is a qualified language capability component available to an AION/Astra system.”

Ollama is a localhost runtime interface. Qwen, Llama and Breeze are upstream families. GGUF/HF files and LoRA adapters are storage/distribution layers. LoRA and controlled intervention are distinct methods.

The four registered Research Proposals have `implementation=NOT_STARTED`, `qa_status=QA_HOLD`, `canonical_effect=NONE` and no execution triggers. They do not create a language model, dataset, adapter, Runtime authority, identity, preference or subjectivity conclusion.
