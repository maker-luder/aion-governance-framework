# Glossary

| Term | Normative meaning |
|---|---|
| CANDIDATE_ARTIFACT | A versioned engineering candidate under QA_HOLD; no identity or authority. |
| APPROVED_CAPABILITY_ARTIFACT_CANDIDATE | Gate-reviewed candidate awaiting explicit Owner promotion. |
| APPROVED_CAPABILITY_ARTIFACT | Exact scoped engineering artifact approved for a stated capability/environment; not AION/Astra or canonical identity. |
| Language Core | LANGUAGE_CAPABILITY_LAYER / LANGUAGE_PROCESSING_COMPONENT, not an Identity Core. |
| Research Proposal | Planning record with implementation NOT_STARTED and no execution side effect. |
| SCOPE_HOLD | Owner scope/resource decision; not an AI preference, refusal or feeling. |
| PROFESSIONAL_METHOD_TRANSLATION | Translation of professional QA/administrative methods into bounded candidate capabilities; not personality, memory or consciousness transfer. |
