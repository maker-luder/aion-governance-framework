# Consciousness Theory Indicator Crosswalk — v0.1.0

Research-only crosswalk that prevents a consciousness theory, an engineered analogue, and an ontological conclusion from collapsing into one claim.

## External precedent

Public consciousness-related engineering projects such as `tlcdv/the_consciousness_ai` implement theory-inspired mechanisms including GNW-like broadcast, IIT-style integration metrics, affective regulation, and self-model candidates. AION uses those projects as external comparison material, not as authority and not as copied implementation.

## Contract

Every record must preserve:

```text
THEORY
PREDICTION
ENGINEERED_INDICATOR
OBSERVATION
ALTERNATIVE_EXPLANATION
SOURCE_REF
```

A complete record can establish only an indicator-level result.

```text
ENGINEERED_INDICATOR != THEORY_CONFIRMED
THEORY_CONFIRMED != CONSCIOUSNESS_ESTABLISHED
CONSCIOUSNESS_CONCLUSION = NOT_ESTABLISHED
```
