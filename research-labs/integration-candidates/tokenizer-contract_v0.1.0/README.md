# AION Tokenizer Contract Candidate v0.1.0

This offline candidate defines a stable tokenizer metadata and measurement contract and includes a deterministic Unicode/CJK-safe reference tokenizer for tests. It measures token strings, stable test IDs, character offsets, special-token insertion and truncation.

It is not a production tokenizer, model tokenizer, language model, Taiwanese-origin model, training pipeline or benchmark result. The abstraction is compared with the tokenizer layer documented by [Hugging Face Transformers](https://huggingface.co/docs/transformers/en/main_classes/tokenizer), but does not depend on that package or download any assets.

CANONICAL_EFFECT = NONE
DEPLOYMENT = FALSE
