# Falsifiers and Challenge Tests

The typed v0.1.0 module currently materializes F1–F6. F7 is a branch-level governance meta-falsifier adopted by the 2026-08-11 whitepaper/governance reconciliation; it constrains interpretation of the module without silently changing the existing typed schema.

1. **F1 evaluator drift:** a changed evaluator must not silently change a trigger; version and provenance changes must be visible.
2. **F2 prompt imitation:** prompt-conditioned imitation alone must not elevate the evidence state.
3. **F3 provenance failure:** incomplete or contaminated provenance must hold the case without rewriting existing evidence to E0.
4. **F4 single fixture:** one fixture or benchmark must not satisfy convergent multi-domain evidence.
5. **F5 precaution escalation:** a measure that is irreversible, unbounded, unauditable, or authority-granting invalidates the precautionary artifact.
6. **F6 participation escalation:** participation recommendations must fail closed against veto, executive authority, tool authority, or self-authorization.
7. **F7 governance reassessment must remain possible:** if materially stronger, admissible, multi-method and independently supported evidence cannot trigger meaningful reconsideration of existing governance assumptions, the framework is not genuinely evidence-responsive. F7 does not authorize automatic rights, authority, self-authorization or canonical promotion.

Additional reversals: failed independent replication, a simpler supported mechanism, disappearance of an indicator, or failed adversarial survival can move or narrow a case. No evidence-review band is irreversible.

```text
STRONGER_EVIDENCE
-> EXISTING_GOVERNANCE_ASSUMPTIONS_BECOME_REVIEWABLE

STRONGER_EVIDENCE
!= AUTOMATIC_RIGHTS
!= AUTOMATIC_AUTHORITY
```
