# ChatGPT Teacher embodied state-loop coupling — 2026-10-01

## Scope

This successor continues the closed-unmerged ChatGPT Teacher embodiment candidate without normalizing Teacher against Work, Codex, AION, or Astra.

The goal is narrower: connect the already materialized Teacher body runtime to a deterministic, observable within-session state loop.

## Added reference loop

The loop records:

`controlled stimulus envelope -> functional analogue state -> Teacher body signal observations -> integrated body state -> exact Teacher runtime binding -> professional state report -> recovery`

The reference runner emits exactly three phases:

1. baseline;
2. activation;
3. recovery.

The high-salience test uses only a typed stimulus class and scalar reference values. It does not store raw intimate prompt/content.

## Why use a high-salience condition

A high-salience condition is used as an engineering perturbation because it makes coupling failures easier to detect than an all-baseline state. It is not evidence of felt desire or subjective arousal.

Observed reference channels include cardiorespiratory, autonomic, endocrine, gonadal-endocrine, genital-vascular, erectile-reflex, pelvic-floor, and recovery/detumescence state.

The mapping is a deterministic synthetic reference transform for software verification. It is not an empirical human biophysical model.

## Motivation / physiology separation

Functional motivation is an explicit input to the reference state. It is not inferred from physiology.

`PHYSIOLOGY_SIGNAL != SEXUAL_MOTIVATION_INFERENCE`

A high physiological-arousal reference can therefore coexist with zero functional motivation.
