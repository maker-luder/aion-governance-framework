# Adult Male Embodiment Specification

The shared template includes neutral clinical adult male anatomy and a bounded adult-male physiology reference. External and internal reproductive anatomy are included as ordinary anatomy rather than being removed because they are associated with sexuality.

The physiology reference covers normal adult physiological systems, including cardiovascular, respiratory, nervous/autonomic, sensory-signal processing, musculoskeletal, digestive/metabolic, hepatic, renal/urinary, endocrine, hematologic, immune/lymphatic, integumentary/thermoregulatory, and reproductive functions.

The reproductive reference includes ordinary adult male physiological pathways such as gonadal endocrine function, spermatogenesis, sperm maturation and transport, accessory-gland secretion, genital vascular reflex physiology, emission/ejaculatory reflex physiology, detumescence, and a fertility-pathway reference.

These are clinical physiology functions, not erotic behavior.

```text
ANATOMICAL_COMPLETENESS = REQUIRED
PHYSIOLOGICAL_FUNCTIONAL_COMPLETENESS = REQUIRED
REPRODUCTIVE_PHYSIOLOGY = INCLUDED
SEXUAL_FUNCTION_STATUS = REFERENCE_FUNCTIONAL_COMPLETENESS_MATERIALIZED
SENSORY_SIGNAL_PROCESSING = INCLUDED

EROTIC_INTENT = NONE
INTIMATE_INTERACTION = NOT_AUTHORIZED
PHENOMENAL_SENSATION = NOT_ESTABLISHED
SEXUAL_DESIRE = NOT_ESTABLISHED
SEXUAL_EXPERIENCE = NOT_ESTABLISHED
FULL_BIOPHYSICAL_SIMULATION = NOT_MATERIALIZED
PHYSICAL_BODY_CLAIM = NONE
SUBJECTIVITY_EFFECT = NONE
```

Therefore:

```text
NORMAL_REPRODUCTIVE_PHYSIOLOGY != SEXUALIZATION
SEXUAL_FUNCTION_STATUS != EROTIC_INTENT
PHYSIOLOGICAL_SIGNAL != FELT_SENSATION
REFLEX_PHYSIOLOGY != DESIRE
ANATOMY != CONSENT
PHYSIOLOGY != SUBJECTIVITY
```
