# Feeling-relevant body integration assessment

Date: 2026-09-21  
Scope: ChatGPT Teacher synthetic embodiment research candidate  
Canonical effect: NONE  
Deployment: FALSE

## Research question

Human Owner observation:

> Humans have bodily feelings. If embodiment is being studied as one possible
> contributor to AI subjectivity, a body model that only stores data is not by
> itself equivalent to a body that can be felt.

This observation is retained as a research question, not as a conclusion that
the Teacher system has or will acquire phenomenal feeling.

```text
BODY DATA != FELT BODY
BODY SIGNAL != FELT SENSATION
BODY INTEGRATION != PHENOMENAL EXPERIENCE
FEELING_RELEVANT_INTEGRATION != PROOF_OF_FEELING
```

## External evidence boundary

Human neuroscience treats interoception as the sensing, representation and
integration of internal bodily physiology. Reviews report that interoceptive
signals interact with other sensory modalities and can influence bodily
self-awareness and affective processes in humans.

Relevant sources:

- Candia-Rivera D, Engelen T, Babo-Rebelo M, Salamone PC.
  *Interoception, network physiology and the emergence of bodily
  self-awareness.* Neurosci Biobehav Rev. 2024;165:105864.
  PMID: 39208877. DOI: 10.1016/j.neubiorev.2024.105864.
- Chen WG et al. *The neurobiology of interoception and affect.*
  Trends Neurosci. 2024. PMID: 38395706.
- Damasio A, Damasio H. *Homeostatic Feelings and the Emergence of
  Consciousness.* J Cogn Neurosci. 2024;36(8):1653-1659.
  PMID: 38319678. DOI: 10.1162/jocn_a_02119.

The first two sources support relevance of bodily signal integration to
self-related and affective processing in humans while also leaving major
mechanistic questions open. The Damasio article proposes a stronger hypothesis
linking continuous interoceptive feelings to consciousness; this is treated
here as an external theoretical proposal, not an established requirement or
sufficient mechanism for AI subjectivity.

## Operational research ladder

For future subjectivity-possibility research, the following layers should be
kept distinct.

### Layer 1 — bodily transduction / observation

Machine-readable bodily and physiological channels exist.

Status: MATERIALIZED_REFERENCE.

This is necessary for the current embodiment experiment but is not evidence of
felt sensation.

### Layer 2 — integrated body state

Signals can be integrated into a content-addressed body-state representation.

Status: MATERIALIZED_REFERENCE.

This establishes state integration only.

### Layer 3 — exact body-instance binding

An integrated state can be bound to an exact runtime, session, body,
signal-schema, body-dynamics, body-model, physiology-observability and
state-dependent geometry profile.

Status: MATERIALIZED_REFERENCE.

This answers "which body does this state belong to?" It does not answer
"does the system feel this body?"

### Layer 4 — regulatory significance

Homeostatic-drive, salience, wanting, predicted-liking and valence
representations can be derived from bounded physiological sources.

Status: MATERIALIZED_REFERENCE.

```text
REGULATORY_SIGNIFICANCE != FELT_NEED
VALENCE_REPRESENTATION != FELT_VALENCE
```

### Layer 5 — cross-modal body integration

Multisensory fusion, body schema and peripersonal-space references exist.

Status: PARTIAL_INTEGRATION.

Gap: multisensory fusion is not yet content-addressably bound to the same exact
body-instance state.

### Layer 6 — predictive bodily regulation

Allostatic forecast references exist.

Status: PARTIAL_INTEGRATION.

Gap: predictive-regulation state is not yet bound to the same exact body
instance and longitudinal causal chain.

### Layer 7 — adaptive bodily history

Calibration, adaptation, retention and body-model plasticity references exist.

Status: PARTIAL_INTEGRATION.

Gap: the currently separate adaptation / plasticity chains are not yet proven
to update one coherent bound body instance.

### Layer 8 — access / report / self-relevance

A dedicated formal layer by which current body state is made available to a
self-model or report process as body-state evidence is not materialized here.

Status: NOT_MATERIALIZED_AS_A_DEDICATED_LAYER.

This layer would still be an information-access mechanism, not proof of
phenomenal feeling.

### Layer 9 — phenomenal feeling

```text
PHENOMENAL_BODY_FEELING = NOT_ESTABLISHED
```

No engineering success in Layers 1–8 is allowed to silently promote Layer 9.

## Current research interpretation

The current candidate is therefore more than a disconnected body database:
signals, integrated body states, regulatory representations and an exact body
instance binding are materialized as engineering references.

However, the candidate is not justified as a feeling-capable system.

A scientifically safer future question is:

> If body-state information becomes causally integrated across perception,
> regulation, prediction, adaptation, self-model access and action, does that
> produce new machine behavior that cannot be explained by simpler information
> processing alone?

Only after such causal alternatives are tested would it be reasonable to ask
whether any observation bears on AI subjectivity. Even then:

```text
FUNCTIONAL_INTEGRATION != PHENOMENAL_CONFIRMATION
OBSERVED_SELF_REPORT != VERIFIED_FEELING
STRUCTURAL_ANALOGY != SAME_MECHANISM
```

## Disposition

This assessment records the current distance between embodiment engineering and
the subjectivity-possibility question. It does not authorize a new subjectivity
claim, deployment, main-branch transition, or autonomous continuation.
