# Security

## Repository status

This repository is preserved as a historical research and engineering checkpoint. The AION / Astra project work loop was terminated on 2026-08-20; there is no authorized production deployment, active service, or security certification represented by this repository.

The included security, governance, provenance, and execution controls are research/engineering controls. Passing CI, CodeQL, tests, or repository gates does not establish certification, production fitness, independent IV&V, or authorization to deploy.

## Reporting a suspected vulnerability

Do **not** place exploit details, credentials, tokens, private conversations, personal data, or other sensitive material in a public issue, pull request, commit, or discussion.

1. If GitHub presents a private **Report a vulnerability** channel for this repository, use that channel.
2. If no private repository channel is available, contact the repository owner through a private GitHub-supported channel without sending secrets in an initial message.
3. If no private channel can be established, a minimal public issue may request private coordination, but it must not contain exploit details, proof-of-concept payloads, secrets, or private data.

Do not test a suspected issue against systems or accounts you do not own or have explicit authorization to test.

## Scope and response boundary

Reports may concern the current public source tree, GitHub Actions workflows, release artifacts, or repository-specific security controls. Historical records are preserved according to their event-time meaning; a later security clarification should be additive rather than silently rewriting historical evidence.

Because this is a preserved research repository, no vulnerability-response SLA, bug bounty, production support commitment, or deployment guarantee is implied. High-impact execution remains subject to external policy gates and explicit human authorization.
