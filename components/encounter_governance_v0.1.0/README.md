# Encounter Governance v0.1.0

This package provides a bounded, default-deny encounter-policy candidate for the AION/Astra governance framework. It checks participant-specific tool scope, namespace write boundaries, approval-authority ranking, and explicit non-inference of shared identity from shared context.

The package is an engineering and governance candidate only. It does not establish identity, subjectivity, consciousness, moral status, legal status, canonical runtime state, deployment, or authority. Policy decisions retain `canonical_effect = NONE` and must remain subject to the repository’s ordinary writeback and human-review gates.

Run the package tests from this directory with `python -m pytest -q`.
