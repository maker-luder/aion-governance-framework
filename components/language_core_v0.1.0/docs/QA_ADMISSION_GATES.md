# QA admission gates

Gates 1–10 cover lineage, source/license, hash, baseline evidence, target effect,
side effects, Traditional Chinese, instruction following, reasoning/coding, and
human approval. Numerical thresholds are deliberately `null / NOT_SET` in this
phase. Missing thresholds or human approval always produce `QA_HOLD`.

No automated transition has canonical effect. `APPROVED` is a data-model state,
not authority to deploy or modify AION／Astra.
