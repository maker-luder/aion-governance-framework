# Architecture and non-claims

The lab is an offline-first experimental subsystem below AION／Astra. Upstream
models are candidate computation bases. A base migration is recorded as
`Runtime／Model Base Migration`; it never means AION／Astra was replaced.

Ollama is a localhost runtime interface. Qwen, Llama, and Breeze are upstream
families. GGUF/HF files and LoRA adapters are different storage/distribution
layers. LoRA and ablation are distinct methods.

This phase does not train, merge, ablate, download, pull, deploy, connect a cloud
model, change canonical documents, or authorize production memory/tools.
Observations are restricted internal records and do not establish causality or
general conclusions about 4B models or Chinese script performance.
