
# AION Project Governance Kernel Candidate v0.4.0

This package is a **shared governance and audit kernel** for the AION research project. It is not Astra and is not an AION runtime or subject.

## Implemented

- strict structured request validation;
- action-based risk policy (not free-text keyword scanning);
- fail-closed pipeline boundaries;
- SQLite audit records with schema versioning;
- input hashing without raw payload retention;
- deterministic policy reasons and matched rule IDs.

## Not implemented

- model inference, identity, autobiographical memory, planning, tool routing, autonomous loops, network access, or production deployment.
