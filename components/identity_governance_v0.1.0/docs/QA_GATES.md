# Twelve candidate QA gates

1. Project identity record exists.
2. Source and lineage recorded.
3. Previous state verified.
4. Hash chain complete.
5. Artifact source and license complete.
6. Runtime manifest complete.
7. Fork inheritance denied.
8. Canonical writeback denied or explicitly approved.
9. No unsupported subjectivity claim.
10. Perspective disagreement preserved.
11. QA evidence complete.
12. Human approval exists.

Missing policy, threshold, evidence, or approval results in `QA_HOLD`.
