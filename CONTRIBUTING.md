# Contributing

This research branch is under an **indefinite freeze effective 2026-08-18**.

Public contribution intake is closed. New research-materialization PRs, feature PRs, runtime work, release candidates, and canonical-promotion requests are not currently accepted on this branch.

This freeze preserves the research checkpoint; it does not declare the research question abandoned.

```text
PUBLIC_CONTRIBUTIONS = CLOSED
NEW_RESEARCH_MATERIALIZATION = NO
NEW_FEATURE_DEVELOPMENT = NO
NEW_PUBLIC_RELEASES = NO
CANONICAL_PROMOTION = NOT_AUTHORIZED
```

A future contribution cycle requires a new explicit Human Owner authorization and a fresh independent ChatGPT architecture/evidence/provenance review.
