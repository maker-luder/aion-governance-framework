# Contributing

This repository is under an **indefinite freeze effective 2026-08-18**.

Public contribution intake is closed. New feature proposals, implementation PRs, research-materialization PRs, release PRs, and canonical-promotion requests are not currently accepted.

This freeze does not mean the research question has been abandoned. If the Human Owner later authorizes a new repository cycle, contribution rules must be explicitly reopened and redefined at that time.

Until then:

```text
PUBLIC_CONTRIBUTIONS = CLOSED
NEW_PULL_REQUEST_INTAKE = CLOSED
NEW_FEATURE_DEVELOPMENT = NO
NEW_RESEARCH_MATERIALIZATION = NO
NEW_PUBLIC_RELEASES = NO
```

Historical issues, pull requests, commits, and contributor provenance remain preserved as historical evidence.
