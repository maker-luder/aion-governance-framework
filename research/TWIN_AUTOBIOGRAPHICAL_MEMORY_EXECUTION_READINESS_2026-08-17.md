- `components/aion_runtime_v0.1.0`
- `components/astra_runtime_v0.1.0`

## 4. Memory write capability — MECHANIC EXISTS, AUTHORSHIP NOT ESTABLISHED

Both runtime classes implement `remember(...)`, which writes content into the bound runtime memory stream and appends a `memory.written` event.

However, `remember(content=...)` receives content supplied by the caller. The current runtime implementation does not by itself establish that the content was generated by AION or Astra as an autonomous autobiographical self-report.

Therefore:

```text
CALLER_SUPPLIED_CONTENT STORED IN AION MEMORY
!= AION-AUTHORED AUTOBIOGRAPHICAL MEMORY

CALLER_SUPPLIED_CONTENT STORED IN ASTRA MEMORY
!= ASTRA-AUTHORED AUTOBIOGRAPHICAL MEMORY
```

Using ChatGPT-authored or Human-Owner-authored text as `content` is allowed only if provenance states that actual origin. It must not be relabeled as runtime-authored memory.

## 6. Existing recall path — NOT PURE READ-ONLY

Both `AIONRuntime.recall(...)` and `AstraRuntime.recall(...)` retrieve memory records and then append:

```text
memory.recalled
```

to the individual runtime state/event lineage.

Therefore existing runtime recall has an observable state mutation.

```text
EXISTING_RUNTIME_RECALL != PURE_READ_ONLY_QUERY
```

This means the current `recall()` methods must not be directly wrapped as read-only MCP operations.

A pure application-layer projection/query path is required before read-only MCP implementation can be considered compliant with existing MCP governance.

## 7. Operator-surface asymmetry — DOCUMENTED, NOT IDENTITY ASYMMETRY

AION currently has a dedicated CLI / read-only HTTP status surface. Astra's lifecycle/migration capabilities are documented as Python-API capabilities and its dedicated operator CLI/network surface is deferred.

This is an engineering/operator-surface asymmetry only.

```text
OPERATOR_SURFACE_ASYMMETRY
!= RESEARCH_STATUS_ASYMMETRY
!= IDENTITY_STATUS_ASYMMETRY
```

It should be considered if a future twin-symmetric MCP adapter expects equivalent application entry points.
